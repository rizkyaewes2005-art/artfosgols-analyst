# Panduan singkat upload dari HP
1. Buka GitHub dan buat repository baru bernama `ARTFOS-GOLD-WEBSITE`.
2. Ekstrak ZIP di perangkat terlebih dahulu jika memungkinkan. Upload semua file dan folder yang ada di dalam folder `ARTFOS-GOLD-REPOSITORY` ke root repo; jangan upload ZIP saja.
3. Import repo baru itu di Vercel.
4. Framework: `Other`; build command kosong; output directory `.`; install command kosong.
5. Deploy untuk halaman publik. Untuk login/daftar member, konfigurasi Supabase mengikuti README dan SQL schema.

Jangan mengirimkan password, secret key, atau service_role key ke chat maupun ke file frontend.
